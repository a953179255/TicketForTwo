看片要 5 步，能不能再少点？

现状病根：每一层都让你做一个不需要现场决定的决定。下面三个方案，从「小改」到「一步直达」，互相不冲突、可以叠着做。

现状：放一部片子要点 5 下 5 步 · 2 步纯过渡

1首页 · 分享画面
→
2选「同步放映」
→
3引导页 · 打开网站
→
4输入网址
→
5点「打开」

第 2 步和第 3 步是纯过渡页：选类型页只在你犹豫时才有用，引导页只是把地址栏藏了一层。 「分享我的屏幕」也一样要白过一次第 2 步。排版不舒服的根源也在这—— 真正要用的东西（地址栏）永远不在你眼前。

方案 A · 进厅即输入 改动最小 · 5 步 → 3 步

删掉引导页这一层：点完「同步放映」直接落在地址栏聚焦、键盘弹起的状态。 引导页里那点内容（收藏夹、粘贴、测试流）压缩成地址栏下面的一排小芯片，想用再用，不用就当它不存在。 「新标签页」该长什么样？浏览器给出的答案是：光标已经在输入框里闪。

方案 C · 链接感应 叠加在 B 上 · 最少 1 步

看片的真实起点往往不是「打开 App」，而是「我在豆瓣/B站/浏览器里复制了一条链接」。 这是最好的捷径入口：打开 App 时发现剪贴板里有一条网址，就浮出一张卡 —— 点一下，开厅、填链接、出邀请，一气呵成。不点就当没看见，绝不上来就抢剪贴板（安卓会弹读取提示，首用给一次说明）。

三案对比 · 我的推荐是 B + C

方案看片步骤投屏步骤动了什么代价 / 风险
现状 53 —每层都要做一次「其实不用现在做」的决定
A · 进厅即输入 33 删引导页；地址栏直接聚焦；收藏/粘贴/上次收成一行芯片 最小。第一次用的人少了说明页（压成一行小字）
B · 首页说人话 21 圆钮改名「一起看片 / 分享屏幕」，选类型页删除；「进入观看」降为底部文字链 首页双圆布局变动（可先出效果图微调）；声音档要挪家
C · 链接感应（叠在 B 上） 1~21 剪贴板检测浮卡：点一下 = 开厅+填链接+出邀请 要处理剪贴板权限提示；「不了」之后不再骚扰

推荐 B + C 一起做：B 把「每层一次多余决定」的结构问题解决掉，C 把「手里已经有链接」这个最高频场景压到一步。 A 是 B 的一部分（B 的「一起看片」点进去就是 A 那个屏），做 B 自然包含 A。 「分享我的屏幕」在 B 里也顺带解决：从三步变一步（点圆 → 授权）。

动手前，三件事请你拍板

问题选项
① 首页布局 现在两颗圆大小相近。方案 B 改成「大圆（一起看片）+ 小圆（分享屏幕）」突出主场景 —— 接受大小分主次，还是两颗一样大只改名字？
② 「进入观看」降级 对方一般点你发的链接直接进来，首页那颗「进入观看」圆钮用得少。降成底部一行文字链可以吗？（手动粘链接的兜底功能还在）
③ 选类型页的去留 彻底删掉，还是保留在「分享设置」里当说明页？我倾向删 —— 名字已经把区别说清了。

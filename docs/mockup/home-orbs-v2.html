这一版改了什么

① 文字全部进圆内：图标 + 名称 + 一句副标，圆外零文字。
② 玻璃质感按 AndroidLiquidGlass 拆解重做：透镜边缘（内侧亮环 + 底部折射暗环）、 双高光（锐利弧线 + 柔光带）、vibrancy（透过玻璃的壁纸被提亮提饱和）、边缘一像素的色散微边。
③ 配色：两颗彩色玻璃透镜 —— 分享是蓝青（主操作，冷色靠前）， 观看是紫罗兰（次操作）；底部设置是无色玻璃。
④ 壁纸加鲜艳：玻璃的 vibrancy 需要底下有颜色可提，换成青/紫/洋红光斑。

试试

按住两个圆 —— 弹性按压 + 阴影收缩；切换深浅色看玻璃在两种壁纸下的表现；勾选标注看尺寸。

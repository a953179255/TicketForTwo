这次改了什么

  1. 分辨率去掉「自定义」格 —— 它本来就不需要：可选范围天然被屏幕卡死。
  2. 「2K」不是一个新档位，而是第三档在你的屏幕上叫什么：采集只能缩小、不能放大， 所以第三档刻度是“原生分辨率”——2K 屏上显示 2K，1080 屏上显示 1080p。
  3. 帧率、码率的「自定义」格保持（这两个是真需要自由填的）。
所以你在模拟器里看到的会是「540p / 720p / 1080p」，装了真机才会看到「720p / 1080p / 2K」。 两边是同一套代码，只是标签按屏幕像素算 —— 不会出现 1080 屏假称 2K 的情况。
